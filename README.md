# AI Agents مع Ollama — من المحادثة البسيطة إلى أول Agent فعلي

مشروع تعليمي يغطّي مفاهيم الـ AI Agents وبناءها خطوة بخطوة باستخدام نموذج لغوي
مجاني يعمل محليًا عبر **Ollama** (بدون أي API مدفوع).

## المحتوى

| الجزء | الملف | الوصف |
|-------|-------|-------|
| 1 | `part1_answers.md` | إجابات المفاهيم النظرية (بكلماتي الخاصة) |
| 2 | `part2_ollama_test.py` | أبسط تواصل مع Ollama عبر `/api/generate` |
| 3 | `part3_chat.py` | محادثة مع ذاكرة (Conversation History) |
| 4 | `part4_reasoning.py` | حلقة تفكير يدوية + استخراج الجواب النهائي |
| 5 | `part5_agent.py` | أول Agent فعلي بأداة حاسبة (نمط ReAct) |

مجلد `screenshots/` فيه لقطات توثّق تشغيل Ollama والمحادثة والاختبارات فعليًا.

## المتطلبات

1. تثبيت [Ollama](https://ollama.com) (مجاني).
2. تحميل نموذج صغير:
   ```bash
   ollama pull llama3.2:1b
   ```
3. مكتبة requests للبايثون:
   ```bash
   pip install requests
   ```

## التشغيل

```bash
python part2_ollama_test.py     # اختبار الاتصال
python part3_chat.py            # محادثة تفاعلية مع ذاكرة
python part4_reasoning.py       # حلقة التفكير خطوة بخطوة
python part5_agent.py           # الـ Agent مع أداة الحاسبة
```

> يجب أن يكون خادم Ollama يعمل على `http://localhost:11434` (يعمل تلقائيًا بعد
> تثبيت Ollama على ويندوز/ماك).

## أهم فكرة في المشروع (الجزء 5)

النموذج اللغوي **ضعيف في الحساب**، لذلك بدل أن يحسب بنفسه، يطلب الحساب بصيغة
`CALCULATE: <expr>`، وكود Python هو الذي ينفّذ العملية فعليًا ويعيد النتيجة —
فتصبح النتائج الحسابية **دقيقة 100%**. هذا هو جوهر فكرة "الأداة (Tool)" في الـ Agent:
النموذج يقرّر ويخطّط، والأداة تنفّذ.
